Install
------------------------------------------------------------------------------

``chatbot_deeplink`` is released on PyPI, so all you need is to:

.. code-block:: console

    $ pip install chatbot-deeplink

To upgrade to latest version:

.. code-block:: console

    $ pip install --upgrade chatbot-deeplink
